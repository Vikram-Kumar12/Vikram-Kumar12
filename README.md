### 👨‍💻 About Me

I'm Vikram Kumar, a full-stack developer from Ranchi, Jharkhand finishing my BCA (CGPA 9.5/10). 

I started freelancing before graduating because I wanted to build things that real users actually depend on — not just assignments.

I've shipped two production apps for clients: a limousine booking platform with live payments and Google Maps route pricing and an AI-powered tutoring platform using RAG + OpenAI + Qdrant.

On the AI side, I work with LangChain, OpenAI API, and vector databases to build systems that actually retrieve and reason over real documents — not just wrap a chatbot API.

- **Open to:** SDE internships, full-time roles, and freelance projects

### 🚀 Client Work

**[Pomp Limousine](https://pomplimo.com)** — Production booking platform for a Singapore-based client
- Built with React.js, Node.js, Express, and MongoDB, supporting distance-based and hourly bookings
- Google Maps API for real-time route calculation and dynamic pricing
- Stripe payments, JWT auth, and automated email notifications

**[Ascension Tutorial](https://ascensiontutorial.com/)** — AI-powered tutoring platform for a Singapore-based education client
- Built with React.js, Node.js, Express.js, MongoDB, OpenAI API, and Qdrant
- Custom RAG pipeline (chunking, embeddings, vector search) so the AI tutor answers from the client's own course material
- Admin dashboard with PDF/DOCX indexing and Stripe subscription management

**[Digital Guru](https://digitalguru.app)** — Agency website
- Animation-rich site built with React.js, Tailwind CSS, Framer Motion, and GSAP
- Improved engagement through targeted micro-interactions and accessible UI components
